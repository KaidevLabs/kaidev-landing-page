Paleta Completa

La paleta de colores de Kaidev está cuidadosamente diseñada para reflejar su identidad: una marca que aúna precisión técnica, elegancia sobria y sensibilidad artesanal. Cada color cumple un rol funcional o expresivo concreto y ha sido seleccionado por su capacidad para comunicar valores como la mejora continua, la claridad estructural y la confianza.

Usos Recomendados

Kaidev Teal: Color de marca. Ideal para logotipo, encabezados, botones principales y enlaces destacados.
Graphite Core: Tipografía principal, estructuras visuales, fondos oscuros y layouts profesionales.
Soft Paper: Fondo general, maquetación limpia, equilibrio visual sin rigidez del blanco puro.
Warm White: Versión cálida del blanco para logotipos sobre fondos oscuros, fondos suaves o interfaces con sensibilidad visual.
Ink Charcoal: Variante refinada del negro puro, utilizada en el logotipo sobre fondos claros. También puede emplearse para textos, íconos o detalles sobrios de alto contraste.
System Grey: Gris técnico puro utilizado para componentes de interfaz como botones secundarios, bordes, líneas divisorias o contenedores funcionales.
Silent Jade: Color decorativo emocional. Ideal para elementos de ayuda, etiquetas informativas suaves o detalles UI que requieren un tono humano sin protagonismo.
